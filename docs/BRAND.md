# Identidade visual

**Nome:** PiP Overlay
**Assinatura:** Seu vídeo. Seu jogo. Seu espaço.
**Descrição curta:** Vídeo do Edge e Chrome sobre o jogo, com conexão automática e editor visual. Windows / DirectX, OpenGL e Vulkan, sem RTSS ou extensão.

| Uso | Cor |
| --- | --- |
| Fundo | `#0F141E` |
| Superfícies | `#19212E` |
| Destaque | `#6CE7C4` |
| Texto principal | `#F3F8FA` |
| Texto secundário | `#9AA9BE` |

Tipografia: Segoe UI, com fallback para Arial e sans-serif. O símbolo representa uma tela com uma segunda imagem no canto. Os arquivos SVG são editáveis, sem fontes externas ou scripts.

- `assets/logo.svg`: símbolo vetorial.
- `assets/banner.svg`: cabeçalho do README.
- `assets/social-preview.png`: imagem 1280 × 640 preparada para compartilhamento social.
- `assets/workspace-016.png`: renderização atual da interface, sem conteúdo pessoal. `editor.png` e `workspace-015.png` são imagens históricas.

Prefira linguagem direta: descreva o que o aplicativo faz e identifique limites. Não use promessas de custo zero, suporte universal ou aprovação pelos fornecedores do jogo/navegador.

A versão inglesa do cabeçalho está em [banner.en.svg](assets/banner.en.svg). As capturas do aplicativo preservam os rótulos reais em português.

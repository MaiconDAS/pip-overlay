# Preferência obrigatória do usuário: proteção do Windows

O usuário determinou: "nunca vai alterar nada do meu Windows sem antes testar para ver se não vai quebrar algo".

- Antes de alterar o Windows, testar a mudança em ambiente isolado ou temporário e verificar os efeitos relevantes. Não usar a instalação real do usuário como primeiro teste de mudanças no sistema.
- A regra inclui configurações do sistema, Registro, serviços, drivers, permissões, segurança, inicialização, componentes e instalação ou remoção de dependências.
- Se não houver como testar adequadamente, não aplicar a mudança. Explicar a limitação e procurar uma alternativa que preserve o sistema.
- Não prometer risco zero: informar o que foi testado e os riscos ou incertezas restantes. Preparar reversão para mudanças de sistema que sejam necessárias e tenham sido testadas.
- Preferir desenvolvimento e compilação dentro da pasta do projeto, usando ferramentas já instaladas, sem alterações globais no Windows.
- Esta instrução persiste neste projeto; não afirmar que foi registrada em memória global para todas as conversas.

# Mandatory user preference: protect Windows

English translation of the same project rule above; both editions carry the same requirements.

The user instructed: "Never change anything in my Windows installation without first testing that it will not break something."

- Before changing Windows, test in an isolated or temporary environment and verify the relevant effects. Never use the user's actual installation as the first system-change test.
- This includes system settings, registry, services, drivers, permissions, security, startup, components, and dependency installation/removal.
- If adequate testing is unavailable, do not apply the change. Explain the limitation and seek an alternative that preserves the system.
- Do not promise zero risk. Report what was tested and remaining risks or uncertainties. Prepare rollback for necessary system changes after testing them.
- Prefer development/builds inside the project with existing tools and no global Windows changes.
- This instruction persists in this project; do not claim it was saved as global memory for every conversation.
